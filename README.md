# 大口径望远镜自适应光学（AO）校准控制台

一个零依赖、可直接在浏览器打开的自适应光学校准流程实时仿真与可视化单页应用。
面向「大口径天文望远镜实时关联镜面形变、大气扰动、导星位置与最终成像质量」的场景，
强调**波前误差被逐步修正的过程**、**中心/边缘取舍的直观标注**、**多策略同步对照**、
以及**三类异常的不同恢复路径与完整决策历史**。

## 运行

直接用浏览器打开 `index.html` 即可（无需构建、无需服务器、无外部依赖）：

```bash
open index.html          # macOS
# 或双击 index.html
```

## 它在仿真什么

- **大气湍流屏**：解析无限延伸的 Kolmogorov 型冻结流波前，随风向刚体平移；
  视宁度 `seeing`、天顶角（气团）、风速、积分时间均可实时调节。
- **变形镜（DM）**：六边形排布的 ~190 个执行器，高斯影响函数、加权最小二乘控制、
  泄漏积分器、执行器行程限幅与去活塞；支持手动冻结/解冻与失步自动隔离。
- **夏克-哈特曼波前传感器（SH-WFS）**：20×20 子孔径，输出平均斜率（含光子/读出噪声），
  经 Southwell 型 SOR 泊松重建还原波前。
- **导星**：轴上亮/暗自然导星（NGS）与高空钠激光导星（LGS，含等晕角误差）。
- **成像质量**：由中心科学场 RMS 经 Maréchal 近似得到 Strehl，并给出 FWHM 与 50% 能量半径。

## 三套校准策略（相同观测条件下同步运行）

| 通道 | 策略 | 特点 |
| --- | --- | --- |
| 整体最小二乘 ILS | 全场统一权重积分闭环 | 稳健、中庸 |
| 分区加权 Zoned-LS | 中心/边缘分区加权 | 抬中心权重可压中心 WFE，但边缘自由度被挪用而恶化 |
| 风预测 Predictive-LQG | 冻结流前向外推 | 高风速下残差更低；对云层噪声敏感，异常时主动 HOLD |

## 交互

- 左侧：调观测条件、**选择校准星**、调中心/边缘分区权重、查看冻结执行器。
- 中央：五种视图切换 —— 波前残差相位、镜面/执行器（点击圆点冻结/解冻、修复失步）、
  夏克-哈特曼子孔径、科学成像 PSF、导星相机；下方为中心/边缘 RMS、Strehl、FWHM。
- 策略卡：送入大图、中心优先/边缘优先，卡上实时显示残差缩略图与取舍提示。
- 底部：三策略中心（实线）/边缘（虚线）WFE 60 秒滚动收敛曲线与策略说明。

## 取舍标注

当某项调整改善中心却恶化边缘（或反之）时：

- 大图与策略卡上出现红/绿弧与文字横幅；
- 决策历史中记录一条「取舍」事件（含当时中心/边缘 WFE 快照）。

## 异常注入与恢复路径（右侧按钮）

- **云层遮挡**（4–8s，透过率骤降）：ILS / Zoned 降增益慢闭环；Predictive 主动 `HOLD` 冻结指令，云隙后软启动恢复。
- **执行器失步**：自动冻结失效执行器（红色），状态转 `ISO`，由相邻执行器补偿后重新锁定；可在镜面视图点击红点「修复」。
- **导星丢失**：ILS / Predictive 进入 `REACQ` 螺旋搜索重捕获；Zoned 走 `FALLBACK` 切换备用 LGS（引入等晕误差，主星恢复后切回）。

右侧「全部决策历史」按时间倒序保留用户操作、异常、恢复与取舍（含每条时刻的中心/边缘 WFE），
可按类别过滤，并通过顶部「导出决策历史(JSON)」一键下载全部时序与各通道决策。

## 其它

- 顶部支持暂停、1×/2×/4× 速度、单步与全部复位。
- 纯前端数值仿真，所有物理量为教学/演示用的经验标定，不代表具体在役望远镜参数。
